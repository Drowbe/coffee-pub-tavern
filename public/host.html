Managed AI

The AI services this host offers every environment, one per company: set a key (or give the server AI_OPENAI_KEY or AI_ANTHROPIC_KEY) and that company is offered with a model chosen for it; change the model here if you like. An environment picks one of them (Managed) or sets up its own on its AI configuration page, and enables it there either way. A key stays here and is never shown to an environment.

Maps

The map every environment shows: the files in the host's own folder, all of them together. Only a host admin puts files here or cuts a region. Copy a PMTiles file into the folder below, or cut one from a world file.

The world PMTiles file that regions are cut from. Protomaps publishes a daily build at https://build.protomaps.com/YYYYMMDD.pmtiles, where YYYYMMDD is the build's date, such as 20260924; any recent date works.

Add a region

Type a place — a country, a city, a region — and the host will find it, show roughly how large the cut would be, and add it to the files above once you confirm. Nothing downloads until you say so. For basic coverage everywhere, skip the search and instead, at a low zoom — meant to sit underneath detailed regional cuts, not replace them.

Maximum zoom is how much detail the cut keeps, not how far it covers. 10 or below shows towns and the roads between them, not individual streets; 14, the default, shows streets and buildings; 15 is the most detail this can offer. Higher means a far bigger file for the same area. Minimum zoom trims the shallow end: leave it at 0 for a file meant to stand alone, or raise it when a wider, lower-zoom file already covers those zooms. Check size shows the real cost before anything downloads.
