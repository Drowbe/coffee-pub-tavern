Everyone's room

Room

Decides which image sections show up for this room on a member's own profile page, and which ones Coffee Pub Studio offers to publish for it.

Link icon

Shown on the button next to Join, and in the call toolbar, once a launch link is set above.

Modules

Modules with a room panel. Tick one to make it available to this room's members, in the Modules button on the call toolbar. A module marked on for every room is set on the Modules tab of Manage.

Module settings

What each module does in this room. Room moderators can change these too.

Members

Click a player to add or remove them from this room -- saves as you click.

Invite to register

A link that signs someone up with a real account and drops them straight into this room (and the Lobby, like everyone). Works even while general sign-up is off. Single use, expires after 7 days.

Guest link

Anyone with this link joins this room with just a name -- no account, no invite needed. Anyone already at the table can also manage this from the room itself, not just here.

Allow Guests is off for this room -- turn it on above to use this.
