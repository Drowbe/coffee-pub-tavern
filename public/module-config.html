Add a region

Type a place — a country, a city, a region — and the server will find it, show roughly how large the cut would be, and add it to the file list above once you confirm. Nothing downloads until you say so. For basic coverage everywhere, skip the search and instead, at a low zoom — meant to sit underneath detailed regional cuts, not replace them.

Maximum zoom is how much detail the cut keeps, not how far it covers. 10 or below shows towns and the roads between them, not individual streets; 14, the default, shows streets and buildings; 15 is the most detail this can offer. Higher means a far bigger file for the same area. Minimum zoom trims the shallow end: leave it at 0 for a file meant to stand alone, or raise it when a wider, lower-zoom file (like "cover the whole world", above) already covers those zooms, so the two do not both carry the same low-zoom tiles. Check size shows the real cost for the box and zoom range you've chosen before anything downloads.

Saved search results

Places the outside search service has returned are kept on this server, so later searches use them first. A place is used when someone picks it or saves it as one of their places; used places are kept when you purge the unused ones.
